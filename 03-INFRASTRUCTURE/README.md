# 03 — Infrastructure

Guides for cloud automation, virtualisation, and remote networking. Covers AWS cleanup, running Windows from a bare-metal disk in a VM, and setting up remote SSH access from anywhere.

```
03-INFRASTRUCTURE/
├── cloud-management/
│   └── aws-nuke-everything.sh       # ⚠️ Deletes all AWS resources across all regions
│
├── virtualization/
│   ├── WINDOWS-AS-VM.md             # Boot a bare-metal Windows install inside VirtualBox on Linux
│   └── install_pixel9pro_emulator.sh # Android SDK Pixel 9 Pro emulator setup on Arch
│
└── networking/
    └── remote-ssh-desktop.md        # SSH remote access with DDNS and port forwarding
```
